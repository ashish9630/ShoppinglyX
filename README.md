# ShoppinglyX 🛒

ShoppinglyX is a Django-based e-commerce web application developed to demonstrate the core workflow of an online shopping platform. The project focuses on building dynamic web pages, handling backend logic, and integrating the database using Django.

## 🚀 Features
- Product listing with images and details
- Dynamic data rendering from the database
- Media handling for product images
- Clean and responsive user interface
- Well-structured Django project following MTV architecture

## 🛠 Tech Stack
- Backend: Python (Django)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite
- Framework: Django

## 📂 Project Overview
This project follows Django’s standard project structure, utilizing models, views, templates, and URL routing to manage data flow efficiently.
